# Aslam Khan Academy — Premium Website Build

This build implements the requested logo-led visual system, simplified conversion-focused navigation, project-based course architecture, career-goal selector, individual course pages and a safer scalable local SEO structure.

## Brand system
- Deep violet `#2D0F8A`
- Royal purple `#4020B4`
- Electric blue `#1C5DE3`
- Cyan `#32CAFC`
- Plus Jakarta Sans + DM Sans

## Important deployment notes
1. Replace/confirm the phone/email if needed.
2. Add a **verified academy street address** before enabling LocalBusiness address schema or Google Maps embeds.
3. Add real student testimonials, instructor credentials, placement outcomes and certification claims only after verification/permission.
4. Apache deployments can use `.htaccess` to 301 old keyword pages into canonical topic clusters. Legacy files also contain noindex meta-refresh fallbacks.
5. The site uses Bootstrap/Bootstrap Icons from CDN and Google Fonts.

## Local SEO
Canonical pages are grouped by topic under `/seo/varanasi/` rather than publishing dozens of near-duplicate pages. A reusable template and guide are in `/seo/_templates/` and `/seo/SEO_TEMPLATE_GUIDE.md`.
